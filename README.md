# Vở Ôn Toán

Web app ôn toán cho 2 bé (lớp 2 và lớp 4), một file `index.html` duy nhất, mở thẳng bằng trình duyệt là chạy.

- Lặp lại ngắt quãng bằng FSRS-4.5, lập lịch theo từng kỹ năng (không theo từng câu).
- Câu hỏi sinh ngẫu nhiên theo kỹ năng; chấm điểm Again/Hard/Good/Easy từ đúng/sai, có xem gợi ý không, và thời gian làm.
- Trang phụ huynh: độ nhớ từng kỹ năng, lịch ôn, luyện riêng 5 câu, sao lưu/nhập dữ liệu.
- Dữ liệu lưu trong `localStorage` của trình duyệt (key `vo-on-toan-v1`).
